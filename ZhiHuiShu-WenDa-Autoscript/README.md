# 知到智慧树问答互动分全自动脚本

智慧树（知到）网课「问答」互动平时分全自动脚本，基于 ScriptCat（脚本猫）+ Tampermonkey 运行。

**当前版本：v2.9.0**

## 功能一览

- **回答模式（默认）**：自动取列表前 50 个提问，逐题打开子页面 → AI 生成回答 → 自动发布；答完当前批次自动滚底加载下一批；每答满 5 题自动刷新与官方数据比对
- **提问模式**：每隔固定时间自动点击「提问」→ AI 生成新问题 → 自动发布（默认目标 10 条）
- **脚本答题计数**：官方数字更新有延迟，脚本自己计数，达标自动刷新复核
- **题目三状态记忆**：未回答（红）/ 已回答（绿，自动跳过）/ 无法回答（橙色删除线）
- **父子页面架构**：详情题在子页面作答，答完自动汇报并关闭，父页面挂起等待互不干扰
- **Material Design 3 悬浮面板**：可拖拽、可折叠、位置记忆、模式切换、运行日志窗、答题监控窗
- **安全机制**：检测到二维码验证自动暂停，人工验证后自动继续

## 安装使用

1. 浏览器安装 [ScriptCat](https://docs.scriptcat.org/) 或 Tampermonkey
2. 新建脚本，把 [`知到智慧树全自动刷问答平时分助手.user.js`](知到智慧树全自动刷问答平时分助手.user.js) 全文粘贴保存
3. 打开智慧树课程问答页面（`qah5.zhihuishu.com/qa.html`），在面板设置里填入自己的 AI API Key
4. 详细说明见 [docs/技术文档.md](docs/技术文档.md)
