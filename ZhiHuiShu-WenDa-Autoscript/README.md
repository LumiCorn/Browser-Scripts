# 知到智慧树问答互动分全自动脚本

智慧树（知到）网课「问答」互动平时分全自动脚本，基于 ScriptCat（脚本猫）+ Tampermonkey 运行。

**当前版本：v3.4.0**

## 功能一览

- **回答模式（默认）**：自动取列表前 50 个提问，逐题打开子页面 → AI 生成回答 → 自动发布；答完当前批次自动滚底加载下一批；**做满目标即暂停，不再自动刷新页面**
- **停止条件（双保险）**：官方「我的回答」≥ 回答目标（默认 50）**或** 本次脚本已答 ≥ 安全上限（默认 100），任一先到即停。脚本计数只作防无限刷的保险，**达标判断完全以官方数字为准**
- **提问模式**：每隔固定时间自动点击「提问」→ AI 生成新问题 → 自动发布（默认目标 10 条）；首次若无法自动打开提问框，面板会出现「👉 手动唤起提问框」按钮，你点一次后脚本自动接管
- **子页面官方数据回传**：子页面每次打开时页面自带官方「我的回答」数据（来自官方接口，最权威），答题汇报时一并带回；父页面**完全采信**，按**只升不降**合并
- **题目三状态记忆**：未回答（红）/ 已回答（绿，自动跳过）/ 无法回答（橙色删除线）
- **父子页面架构**：详情题在子页面作答，答完自动汇报并关闭，父页面挂起等待互不干扰
- **Material Design 3 悬浮面板**：可拖拽、可折叠、位置记忆、模式切换、运行日志窗、答题监控窗
- **安全机制**：检测到二维码验证自动暂停，人工验证后自动继续

## 安装使用

1. 浏览器安装 [ScriptCat](https://docs.scriptcat.org/) 或 Tampermonkey
2. 新建脚本，把 [`zhihuishu-qa-automation.user.js`](zhihuishu-qa-automation.user.js) 全文粘贴保存
3. 打开智慧树课程问答页面（`qah5.zhihuishu.com/qa.html`）
4. **配置你自己的 AI 接口**：展开右侧悬浮面板的「API 与参数设置」
   - 填入你的 **API Key**（必填）
   - 选择 **供应商 / API 地址**：内置 GPT.GE 中转、DeepSeek、OpenAI、智谱 BigModel、通义 DashScope 预设，也可选「自定义地址…」填任意 OpenAI 兼容地址
   - 选择模型 → 点「保存设置」
5. 详细说明见 [docs/技术文档.md](docs/技术文档.md)

## 关于 API Key

**本脚本不内置任何 API Key，仓库里也没有。**

你需要自备一个 OpenAI 兼容接口的 Key（中转站或各厂商官方 Key 均可）。填入面板后，Key 只保存在**你本机的脚本管理器存储**里（`GM_setValue`），不会上传到任何服务器，也不会写进仓库。

> 贡献代码时请勿提交真实 Key。`.gitignore` 已排除 `.env*`、本地配置与脚本管理器导出文件。
